⚡ Electron
 From Grid Anomaly to Field Action.

Electron is a grid intelligence platform that transforms electricity-distribution telemetry into actionable investigation insights using machine learning, grid analytics, simulation, and voice AI.

🎯 The Problem
Unusual electricity consumption doesn't always indicate theft. Meter faults, communication failures, and legitimate behavioral changes can produce similar anomalies. Simple thresholds often lack the context needed to distinguish them.

 💡 Our Solution
Electron connects anomaly detection with probable-cause analysis, grid-loss correlation, investigation prioritization, and AI-assisted field workflows.

🧠 Core Intelligence Layers
- **Consumer Intelligence:** Analyze consumption patterns and behavioral deviations.
- **Anomaly & Cause Intelligence:** Detect irregularities and investigate possible explanations.
- **Grid Forensics:** Correlate anomalies with available transformer and feeder data.
- **Investigation Copilot:** Support field investigators with evidence-grounded explanations and voice interaction.

🎙️ ElevenLabs Voice Copilot
Electron integrates ElevenLabs for natural-language interaction with controlled backend tools, helping investigators access relevant grid intelligence through voice. The copilot explains available evidence without inventing readings, scores, or findings.

 🧪 Digital Twin
A simulation-oriented testing environment supports controlled telemetry scenarios and comparison against known ground truth, enabling systematic evaluation of anomaly detection and system behavior.

🛠️ Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS, Recharts
- **Backend:** Python, FastAPI, Pydantic
- **ML & Data:** scikit-learn, Pandas, NumPy
- **Database:** PostgreSQL
- **Voice AI:** ElevenLabs
- **Simulation:** Python

🔄 The Electron Workflow
Detect → Diagnose → Correlate → Prioritize → Explain → Investigate → Verify**

Electron treats anomalies as investigation signals, not definitive proof of electricity theft. Its goal is to help utilities move from raw telemetry to better-informed field action.

🔮 Future Scope
Expanded live IoT integration, model explainability, multilingual field workflows, mobile investigation support, and learning from verified investigation outcomes.
